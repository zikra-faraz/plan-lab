# 🧠 Plan Lab – Kanban-style Project Management App

Plan Lab is an end-to-end Kanban-style project management app built using modern full-stack technologies like Next.js, Clerk, Prisma, NeonDB, and Docker.

---

## 🚀 Features

- ✅ Full Kanban-style task management
- 🏢 Create organizations and invite members
- 🔐 Role-based access control (Admin, Member)
- 🧩 Drag-and-drop issue tracking
- ⚡ Real-time UI updates for tasks and issues
- 🧠 Authentication via Clerk
- 🔌 Database powered by NeonDB
- 🛠 Backend logic managed with Prisma ORM
- 🌍 Deployed on Vercel
- 🐳 Dockerized for container-based deployment

---

---

## 🧪 Tech Stack

- **Frontend**: Next.js 15, React, Tailwind CSS
- **Auth**: Clerk
- **Backend**: Prisma ORM, NeonDB (PostgreSQL)
- **State**: React Hook Form, Zod
- **UI**: Radix UI, Lucide, Sonner, Embla Carousel
- **Deployment**: Vercel + Docker Hub

---

## 🐳 Run Locally with Docker

1. **Pull the image** from Docker Hub:

```bash
docker pull zikrafaraz/plan-lab

docker run -p 3000:3000 zikrafaraz/plan-lab
```
